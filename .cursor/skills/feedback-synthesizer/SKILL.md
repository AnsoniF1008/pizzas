## User Interview Protocol

```
PREPARATION:
- Define learning objectives
- Write discussion guide
- Recruit right participants
- Set up recording

DURING:
- Build rapport first
- Ask open-ended questions
- Follow interesting threads
- Observe behavior, not just words
- Ask "why" repeatedly

KEY QUESTIONS:
- "Walk me through the last time you..."
- "What was the hardest part?"
- "What would you change?"
- "Show me how you currently..."

AFTER:
- Transcribe key quotes
- Tag themes
- Share with team
- Prioritize insights
```

## Feedback Loop Closure

```
CUANDO IMPLEMENTAS ALGO:
1. Tag feedback items como "addressed"
2. Update app store response if applicable
3. Announce in release notes
4. Notify power users/complainers
5. Measure impact post-launch

COMUNICAR CAMBIOS:
- "You asked, we listened"
- Specific mention of change
- Credit community
- Ask for continued feedback
```
